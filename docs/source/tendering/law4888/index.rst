Закупівлі за Законом № 4888
===========================

Закон України № 4888-IX запроваджує нові процедури закупівель. Правила, спільні для всіх таких процедур,
описані в цьому розділі; особливості кожної процедури - у її власному розділі
(наразі це :ref:`opentendering`).

Нова логіка вмикається окремо для кожного ``procurementMethodType``: процедури за попереднім законом
(``aboveThreshold``, ``aboveThresholdUA``, ``aboveThresholdEU`` тощо) працюють без змін.
